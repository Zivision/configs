*  Configs
**  GNU Emacs (Doom Emacs)
+  Emacs configuration is in *doom/*
**  Bashrc
+  Bashrc configuration is in *home/*
**  Scripts
The scripts needed to install this project are in *scripts/*

*  Prerequisites
The only thing you need to get started is _git_ itself everything else is installed automatically.

**  Getting Started
In order to get started clone the repository from github with the command below:
#+begin_src bash
git clone https://github.com/Zivision/configs.git
#+end_src

**  Install
To install doom Emacs and setup the configurations, use the _install-sys_ script located in *scripts*
#+begin_src bash
cd configs
./scripts/install-sys
#+end_src

**  Quick Information
This project makes links (via stow) to different directories in the machine

***  List of directories
+  Doom Configuration :: ~/.config/doom/
+  Home Configuration :: ~/
+  Scripts :: ~/.local/bin/
