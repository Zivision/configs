*  How to install
The main way I install this is grabbing a graphical installer ISO from [[https://nixos.org/download/][nixos.org]].
After the initial install, I install git and then clone this repository.

Usually into a Workspace directory under a Misc directory. (But location doesn't matter)
#+begin_src bash
git clone https://github.com/Zivision/configs.git ~/Workspace/Misc/configs
#+end_src

Then run the following command
#+begin_src bash
~/Workspace/Misc/configs/bin/install-system
#+end_src
