*  How to install
The main way I install this is grabbing a graphical installer ISO from [[https://nixos.org/download/][nixos.org]].
After the initial install, I install git and then clone this repository.

Usually into a Workspace directory under a Misc directory. (But location doesn't matter)
#+begin_src bash
git clone https://github.com/Zivision/configs.git ~/Workspace/Misc/configs
#+end_src

After cloning the repository, run *nix-shell* in project root or the command below
#+begin_src bash
nix-shell ~/Workspace/Misc/configs/shell.nix
#+end_src

after that simply run the following command listed below
WARNING: nixbox is the minimal setup and does NOT have NVIDIA drivers. Look at nixos.org (file, not site) or nixos/
#+begin_src bash
~/Workspace/Misc/configs/bin/manage-system -ci nixbox
#+end_src
