Hyprland (hypr/ Directory)

This is my hyprland configuration originally modified from an auto generated one.

For more info on configuring hyprland visit the Wiki

Monitors

monitor = DP-2, 1440x900@74.98, -900x0, 1, transform, 1
monitor = HDMI-A-1, 1920x1080@74.97, 0x0, 1

Programs

$terminal = kitty
$fileManager = dolphin
$menu = wofi --show drun
$editor = emacsclient -cn
$vterm = emacsclient -c -e '(hypr/launch-vterm)'
$eshell = emacsclient -c -e '(hypr/launch-eshell)'
$elfeed = emacsclient -c -e '(hypr/launch-elfeed)'
$scratch = emacsclient -c -e '(hypr/launch-scratch)'
$dired = emacsclient -c -e '(dired ".")'
$emacsMenu = emacsclient -c -F '((name . "emacs-run-app") (minibuffer . only))' -e "(progn (xdg-launcher-run-app) (delete-frame))"

Windows and Workspaces

# Ignore maximize requests from apps. You'll probably like this.
windowrule = suppressevent maximize, class:.*

# Fix some dragging issues with XWayland
windowrule = nofocus,class:^$,title:^$,xwayland:1,floating:1,fullscreen:0,pinned:0

# Bind certain workspaces to certain monitors
workspace = 10, monitor:DP-2, default:true
workspace = 9, monitor:DP-2
workspace = 8, monitor:DP-2
workspace = 2, monitor:HDMI-A-1 default: true
workspace = 3, monitor:HDMI-A-1
workspace = 4, monitor:HDMI-A-1

# Window rule for emacs launchers
windowrulev2 = float, title:emacs-run-app
windowrulev2 = size 600 250, title:emacs-run-app
windowrulev2 = center, title:emacs-run-app
